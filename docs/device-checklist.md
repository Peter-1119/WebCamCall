# 實機測試檢查表

目標裝置：**iPad Safari**（廠內唯一使用的裝置）。桌機 Chrome 僅作開發驗證。
Android Chrome / 桌機 Firefox / Safari 的項目列在最後，目前不列為必測。

測試網址：`https://sfserver.flexium.com.tw/scanner/`，頁首 `build <hash>` 要對到最新 commit。

## 記錄格式

每一項填：✅ 通過 / ❌ 失敗（附截圖到 `pics/`）/ ➖ 不適用。
截圖包含頁首 build 與 stats 區塊。
